- 布阵确认采用事务，仅写 battleSlot 和 battleCompanions，支持保存反馈、失败重试与恢复默认；Rules 备份增加合法阵位校验，未部署至 Firebase。
- 新增村庄右侧两河之间的龙岛草原第1世界入口视觉标记；毛毛虫与飞蛾各一组八帧透明黑影，在缩至60%的入口上各复用两处，支持减少动态效果偏好；入口向左移3%、向下移5%，支持高亮与点击查看待开放预览。
- 返回、小龙资料与标题移至地图内顶层；地图放大，默认从南部展示，可滚动查看北部。
- 南部左下添加远景透明村庄：约 18 户高低错落房屋、水井及生活物件；按背景水域重新排布，增加三座小桥，生硬石柱广场改为小龙游乐场，深黑龙影在村庄四处不对称分布，以不同周期错开循环飞舞。
- 房屋减少约一半；用户随后手动调整容器位置和图片缩放。最新贴图内部将游乐场左移，并对调右上桥与两层房屋。
- 修复村庄撑出地图底边并露出蓝绿色空白，调整村庄纵向锚点并限制地图滚动边界。
- 窄屏采用两行悬浮区，减少动态效果偏好下停止龙影动画。尚未完成真实页面桌面/窄屏目视验收，未发布。

## v1.2.3 — 战前充能与彩虹能量环互动

- 战前答题将能量环作为提交按钮；答对从环心生成彩虹宝石并飞入空槽，答错时环心宝石震颤消散。
- 提供跳过单题、答题后继续下一题或直接进入对战；进入战场时能量环飞至左上角并持续显示。
- 对战模拟选关页主视觉中央显示能量环；悬停/聚焦时展示当前充能数和提示，默认不显示边框或文案。
- 技能悬停、聚焦或选中时显示半透明消耗宝石；成功施放时宝石放大消散并同步扣除环中能量。
- 新增透明底彩虹宝石素材 `assets/battle/actions/energy-pip-rainbow.png`。
- 本地检查通过；用户已确认模拟页圆环位置与默认隐藏文案符合预期。已发布至 GitHub Pages。
